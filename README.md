# TypeFlow · 打字练习室

## GitHub Pages 在线版

仓库已配置 [Pages 部署工作流](.github/workflows/pages.yml)。推送到 `main` 或在 Actions 中手动运行 **Deploy TypeFlow to GitHub Pages**，即可自动测试、构建和部署。

首次启用时，在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**，然后推送代码，或在 Actions 页点击该工作流的 **Run workflow**。不需要设置 PAT、仓库密钥或 `gh-pages` 分支。GitHub 官方流程见 [自定义 Pages 工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

默认地址为 `https://nannan-meow.github.io/TypeFlow/`，实际部署地址以 Actions 的 `github-pages` 环境输出为准。

Pages 版有全部 106 个关卡，在浏览器内评分，并将成绩保存在**当前浏览器**。它不需要启动 Python，切换设备、浏览器或清除网站数据后不会自动同步成绩；练习记录页仍可导出 JSON。在线版不会读取或公开本机 SQLite 数据库，已有本地成绩不会自动迁移到浏览器。

点击右上角的**个人空间**或头像，可以修改昵称、每日练习目标和原文字号，查看练习概况，并进入或导出练习记录。设置在当前浏览器中保存，刷新后仍然保留；在练习中打开该面板会暂停计时，并保留当前输入。

Actions 只上传 `dist/` 中的前端资源和练习素材，构建时会移除素材中的本机绝对路径；后端、日志、浏览器测试文件及个人成绩均不进入 Pages 部署产物。项目使用相对资源路径，可部署到 `/TypeFlow/` 这类仓库子路径，也可用于自定义域名。

本地检查 Pages 产物需要 Node.js 20 或更高版本和 Python 3.10 或更高版本，均无需额外安装依赖：

```powershell
npm test
python -m unittest discover -s tests -v
npm run build:pages
node tests/pages.test.mjs
```

## 本地一键启动版

双击 **一键启动.bat**（或 `Start.bat`），脚本会同时启动前端和后端，准备好后自动打开默认浏览器。保留启动窗口，按 `Ctrl+C` 可停止两个服务。再次双击时会优先打开已经运行的应用。端口被占用时会自动寻找其他端口。

当前电脑已安装 Python，直接双击即可。运行只需要 Python 3.10 或更高版本，不需要 npm、不需要下载依赖，也不需要联网。默认访问地址为 `http://127.0.0.1:8765`，如自动换了端口，以启动窗口中显示的地址为准。

## 练习内容

- **英文**：词组 12 关、句子 12 关、文章 6 关。来自教育、环境交通、科技、工作、健康、文化旅游六个雅思 Task 2 常见主题的原创范文，每篇超过 250 词；不是官方真题范文或官方评分。
- **中文**：词组 26 关、句子 30 关、文章 20 关。提取自 `C:\Users\Administrator\Desktop\MathorCup` 中的 41 篇优秀论文；文章为正文节选，练习页可查看对应论文与 PDF 页码。词组均在原始论文中核对存在。
- 六条路线的所有关卡全部开放，闯关模式也可以任意选择，无需通过前一关。速度和正确率同时达标即可获得该关的通关记录与星级。自由练习计入记录，不累计通关星级。
- 实时速度、正确率、计时、字符标色、星级评价、练习历史、七天时长和 JSON 成绩导出。
- 中文拼音输入法选字期间不判错，选字时间计入练习时间。支持退格纠错、暂停、字体调整与专注模式。

## 评分规则

- 英文速度：正确字符数 ÷ 5 ÷ 实际练习分钟数（WPM）。
- 中文速度：正确字符数 ÷ 实际练习分钟数；空格也按一个字符计算。
- 正确率：当前正确字符数 ÷ 当前输入字符数。退格改对后恢复正确率，历史输入错误只用于鼓励性反馈，不扣分。
- 必须完成全文且同时达到本关速度和正确率要求才通关。不同关卡目标显示在卡片上。
- 闯关目标较宽松：英文从 8 WPM 起步，中文从 6 字/分钟起步，正确率目标为 75% 到 85%。
- 1 星：双目标达标；2 星：正确率至少 90%，且速度达标；3 星：正确率至少 95%，且速度达到目标的 1.1 倍。
- 完成全文即获 60 分基础分，正确率最多再加 25 分，速度最多再加 15 分。未完成全文也按输入进度给予基础分并记录时间。
- 从开始输入计时；按 `Esc` 暂停/继续，切换浏览器标签页时自动暂停，按 `Ctrl+Enter` 可提前结束。开始后请保持计时窗口正常运行。

**词组练习**将标点和符号替换为空格，并合并连续空格；**句子练习和文章练习**保留原有标点，需要按原文输入。中英文都遵循这一规则。文章排版换行合并为空格，无需回车；英文区分大小写。练习区不支持粘贴。

## 数据与文件

所有成绩存放在 `data/progress.sqlite3`，关闭浏览器或重新启动不会丢失。需要备份时，先停止启动窗口，再复制整个 `data` 目录。练习记录页也可以导出全部记录供查看。此版本为单人本地使用，无账号和云同步，导出文件仅用于备份查阅。

素材已打包在 `data/corpus.json`，日常使用不依赖原论文目录，也不会修改原论文。英文主题原稿位于 `tools/ielts_material.py`。如要重新提取中文素材，安装 PyMuPDF 后运行：

```powershell
python tools/extract_corpus.py --source "C:\Users\Administrator\Desktop\MathorCup"
```

提取工具会保留文件指纹、相对路径和页码。它提取同一页内连续正文，合并 PDF 排版换行，过滤公式和乱码；仅词组去掉标点，句子和文章保留原有标点。提取结果不是逐页排版复刻。界面使用较大字号，练习原文默认为 28px，可用 A− / A+ 调节。

## 开发与排查

```powershell
python launcher.py --no-browser
python -m unittest discover -s tests -v
node tests/engine.test.mjs
```

前端为 HTML/CSS/原生 JavaScript，由独立静态服务代理 `/api` 请求；后端为 Python 标准库 HTTP API + SQLite。两个服务仅监听本机回环地址。运行日志位于 `logs/backend.log` 和 `logs/frontend.log`。

若无法打开页面，检查启动窗口是否保留；若看到保存失败，恢复服务后点击重试。未保存的当前成绩会暂存在浏览器，下次刷新时自动补交。正在输入但尚未提交的练习不会跨刷新恢复。
